# FieroNews & Pennock's Fiero Forum Web Archive

**FieroNews.net & Pennock's Fiero Forum Archive** is a dedicated historical preservation project and multimedia time capsule celebrating the Pontiac Fiero community from the broadband era of the early 2000s through the 2010s. Originally created by community archivist Tom ("fieronews") as the net's premier multimedia hub supporting Pennock’s Fiero Forum (PFF) and the Northern Illinois Fiero Enthusiasts (NIFE), the website hosts thousands of preserved community discussions, rare technical documentation, factory service and owners manuals, custom engine swap guides (such as Quad 4 and Archie V8 conversions), production photo archives, and the historic Pennock's Forum CD collection.

The site exists to rescue, protect, and permanently preserve invaluable early-internet automotive culture, grassroots engineering knowledge, and member build logs that are continually threatened by link rot, server shutdowns, and modern web decay. Rebuilt as an open, fully responsive static archive with modern mobile compatibility, an interactive 3D vault entry, offline searchability, and automated syndication for live worldwide Fiero events via FieroHub, FieroNews ensures that decades of irreplaceable community passion, technical ingenuity, and Pontiac heritage remain freely accessible to new and seasoned enthusiasts around the world.

## Living Testbed & Archive Disclosures

### 1. AI Web Development Testbed Mission
Another core mission of this website is to serve as an active experimental testbed for evaluating, benchmarking, and refining modern AI-assisted web development tools and autonomous reverse-engineering workflows. Using the rich, complex historical architecture of the original FieroNews website (legacy PHP-Fusion static HTML tables, vintage CSS, nested iframes, and multi-era forum dumps) provides an authentic, challenging real-world environment for testing automated responsive redesigns, feature porting, and dynamic asset integration.

### 2. Differences from the Original Website (Not an Exact Duplicate)
Please note that this deployment is **not an exact bit-for-bit duplicate** of the original historic website. While the vintage early-2000s aesthetic and historical forum/news content are preserved, key enhancements and differences include:
- **Install Videos Not Yet Ready for Download**: The original broadband installation videos and massive multi-hour media files are not yet packaged or ready for download.
- **Added Retro Terminal Game**: An authentic CRT-styled ASCII roguelike dungeon crawler, **Dungeons of Doom**, has been integrated directly into a new **Games** category with an in-browser playable canvas.
- **Added Worldwide Events Calendar**: A live, filterable Pontiac Fiero events calendar synchronized with [FieroHub.com/events](https://fierohub.com/events/) has been added to keep the global community connected to active shows, cruises, and club gatherings.
- **Added Responsive Layout & Retro Visitor Counter**: Modern CSS media queries and flexbox containers have been introduced so legacy fixed 940px tables scale cleanly on mobile devices and modern desktop screens, accompanied by an authentic rolling odometer visitor counter.
