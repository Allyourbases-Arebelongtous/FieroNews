2.1 Simple Searches
In its simplest form, a search will return all threads in which either any or all of the entered keywords were found (depending on the Default Operator). For example, if the Default Operator is set to "Any Words", and you enter


then this will return all threads that either contain the word "ignition", "coil" or "tachfilter". The score tells you how often the entered keywords were found in a thread.

Since keywords are sought using an exact match, the above example will not find the words "coils", "ignitions" or "tachfilters". This is different from how Volume 1 of PFFCD sought threads.
