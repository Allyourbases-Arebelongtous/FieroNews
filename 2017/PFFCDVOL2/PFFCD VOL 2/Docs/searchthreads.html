2. Searching Threads
PFFCD's search engine has completely changed since Volume 1. The old search engine actually opened evey single thread in search for the entered keywords. Since the number of threads on PFFCD Volume 2 has quadrupled, this was no longer a viable search method. The new search method is much faster, although it can still be slow whenever a lot of threads (thousands) are found. PFFCD will now find all threads within seconds, but for creating the on-screen summary it needs to open all found threads.
