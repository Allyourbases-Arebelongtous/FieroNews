1. Quick Start
After you have started PFFCD, the main search window will appear on your screen. By default, PFFCD will search for keywords through the entire thread and in all forums. For a simple search test, enter the following in the Search field:


Note that the entered text is not case sensitive. In other words, searching for "ignition" will render the same search results as "IGNITION".

To start the search, press the Start button:


The program will now start searching through all the threads on the CD. At the bottom-left of the search window you will see the progress indicator:


At any time during the search, you can interrupt the search and display the threads found so far by pressing the Stop button:


When the program has finished searching - or after you have interrupted the search - the Threads View Window will display the found threads. Each row contains the thread topic, the thread originator, the date of the first post, the total number of posts in this thread, a search score and the forum the thread was found in. The search score indicates how often the keywords were found in the thread.

To view a thread, either double-click the thread or highlight it and click the View button:


PFFCD uses your default internet browser to view threads. If your browser is not already open, it will be opened automatically by PFFCD. On some systems this will also pop up the Dial-Up window. Since all the information needed by PFFCD resides on the CD, you do not need to make an internet connection. Either close the Dial-Up window, or choose "Work Offline".
